# E0: Meta runtime smoke gate

## Goal

Muse Spark 1.3 Contributor (`muse-spark-1.3-contributor`) must complete a
scripted five-call MCP sequence in at least 9 of 10 fresh trials. The canonical
target is Meta Model API; when no `MODEL_API_KEY` is available, the same model
through the OpenCode Go gateway is used as a clearly-labelled fallback. Record
every trial's pass/fail result and any exact error text; latency and token
counts are recorded only when the route exposes them.
